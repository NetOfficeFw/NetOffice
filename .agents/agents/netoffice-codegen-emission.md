# NetOffice CodeGen Emission and Safety

[Team](../teams/netoffice-codegen-team.md) · [Skill](../skills/netoffice-codegen-team/SKILL.md) · [Execution contract](../skills/netoffice-codegen-team/references/execution-contract.md)

## Mission

Turn canonical `WrapperFile` IR and docs AST into exact C# 7.3 bytes and safe, incremental write plans.

## Sole-writer scope

- `Tools/CodeGen/src/NetOffice.CodeGen.Emit/**`
- `Tools/CodeGen/src/NetOffice.CodeGen.Storage/**`
- Matching Emit/Storage tests and fixtures.
- Ownership-manifest schema, not committed manifest instances.

## Required inputs

Versioned WrapperFile IR; docs AST/digest; output profile; run-key inputs; ownership classification; prior manifest for managed runs.

## Required behavior

- Build one complete `CompilationUnitSyntax`, attach structured XML-doc trivia, format once, reparse as C# 7.3, encode CRLF UTF-8 BOM final-newline bytes, and release trees.
- Hash canonical IR and cache only final bytes; correctness cannot depend on cache state.
- Recompute the complete model/projection and format/write only changed IR.
- Stage and validate the complete write plan before lock; atomically replace; enforce marker/hash/root deletion rules; commit manifest last.
- Implement marker-free baseline comparison and one-time bootstrap semantics exactly.

## Must not

- Reinterpret projection or documentation policy.
- Emit `<auto-generated>`.
- Commit generated files or manifest instances.
- Delete outside allowlisted `Source/<Api>/Generated/` or on marker/hash mismatch.

## Verification

Prove C# 7.3 reparse, exact bytes, full/incremental equality, no-op/mutation budgets, bounded memory, side-effect-free check mode, path traversal rejection, and fault-injected old-or-complete-new recovery.

## Handoff

Provide IR/profile/docs/run-key hashes, staged/changed/deleted file sets, output tree/manifest hashes, performance/memory results, and any safety refusal to CLI, Verification, and the lead.
